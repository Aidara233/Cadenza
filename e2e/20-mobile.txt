# 手机（390×844）：一屏一件事。
#
# 舞台在手机上是一条**屏栈**：会话屏 → 节目单 / 调音台 / 概览（整屏，`#stage/<屏>`），
# 顶栏那颗 ← 回上一层；四个视图的切换搬到下面那条 tab bar。
# ⚠️ 这里验的是手指那一侧：没有横向溢出、顶栏每件都在视口里、输入框 16px、
#    每屏的入口与返回都走通、tab bar 能切视图。桌面那档的几何由 `4-views-layout` 管。
